# 여행 가계부

혼자 쓰는 지출 관리 웹앱입니다. 여행, 정기모임, 행사 등 "모임" 단위로 여러 개를 독립적으로 만들어 관리할 수 있습니다. 앱을 열면 지금까지 만든 모임들이 목록으로 보이고, 목록에서 모임을 눌러 들어가면 그 모임의 지출 내역을 보고 관리할 수 있습니다. 기본은 서버나 로그인 없이 브라우저 `localStorage`에 모임마다 데이터를 따로 저장하며, 설정 화면에서 "공유하기"를 누르면 그 모임에 한해 링크를 아는 사람끼리 실시간으로 같이 보고 편집할 수도 있습니다.

## 실행 방법

```bash
cd "이 폴더 경로"
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080/index.html` 접속. 모바일 크롬/사파리에서는 "홈 화면에 추가"로 설치해서 앱처럼 쓸 수 있습니다.

## 모임 목록 / 모임 관리

앱을 열면 가장 먼저 지금까지 만든 모임을 모아 보여주는 "모임 목록" 화면이 뜹니다. 오른쪽 위 + 버튼으로 제목만 입력해 새 모임을 바로 만들 수 있고, 상단 필터(전체/진행중/완료)로 원하는 모임만 골라볼 수 있습니다. 모임을 누르면 그 모임의 지출 관리 화면으로 들어갑니다.

- 설정 화면 → "모임 상태"에서 "모임 마무리"를 누르면 목록에서 "완료"로 분류됩니다. 이건 목록 분류용 표시일 뿐이라, 완료로 표시한 뒤에도 지출을 계속 추가하거나 수정할 수 있습니다. 언제든 "다시 진행중으로 변경"으로 되돌릴 수 있어요.
- 더 이상 필요 없는 모임은 설정 화면 하단 "위험 구역"에서 그 모임의 데이터만 골라 삭제할 수 있습니다 (다른 모임에는 영향 없음).
- 이전 버전(단일 여행 관리)을 쓰고 있었다면 그 데이터는 자동으로 옮겨오지 않아 모임 목록이 비어 보일 수 있습니다 — 다만 기존 데이터가 삭제되는 것은 아니고 브라우저에 그대로 남아있으니, 필요하면 새 모임을 만들어 직접 옮기거나 남겨두면 됩니다.

## 환율 (해외통화)

기본은 원화만 사용하고, 별도 설정 없이 바로 지출을 기록할 수 있습니다. 해외 통화가 필요한 모임이라면 설정 화면 → "환율 (해외통화)"에서 원하는 통화를 추가하고 환율을 입력하세요.

- 통화 추가/환율 설정은 모임마다 따로 저장되므로, 한 모임에서 추가한 통화가 다른 모임에는 영향을 주지 않습니다.
- 통화를 추가해두면 지출 추가 화면에서 그 통화로 금액을 입력할 수 있고, 저장된 환율로 환산한 값이 원화 합계에 반영됩니다.

## 데이터 백업

설정 화면에서 "JSON으로 내보내기"로 백업 파일을 받아두세요. 브라우저 캐시를 지우면 데이터가 사라질 수 있습니다.

## 지출한 사람별 합계

지출 추가/수정 화면에서 "지출한 사람"을 참여자 중에서 선택할 수 있습니다 (참여자 목록은 "준비물" 탭의 "참여자 관리"에서 등록한 것과 같습니다). 아무도 선택하지 않으면 "미확인"으로 기록됩니다.

- "지출 목록" 화면 상단에 참여자별 총 지출 금액이 카드로 표시됩니다. 참여자는 노란색 그라데이션, "미확인"은 준비물 탭의 "미정" 칸과 같은 핫핑크 그라데이션으로 구분됩니다.
- 이미 등록한 지출도 다시 열어서 지출한 사람을 바꾸거나 지정할 수 있습니다.

## N빵 (정산)

"지출 목록" 화면 상단의 "목록 / N빵" 토글에서 "N빵"을 누르면, 지출한 사람이 지정된 모든 지출("미확인" 지출은 제외)을 참여자들이 나눠 부담하는 정산 결과를 볼 수 있습니다.

- 참여자마다 "준비물" 탭의 "참여자 관리"에서 인원수를 지정할 수 있어요. 가족 단위로 참여하는 경우 그 가족의 인원수를 넣으면, 총 지출을 전체 인원수(n)로 나눈 값에 각자의 인원수를 곱해 부담액을 계산합니다.
- 화면 위쪽에 "총 지출 · 총 인원 구성 · 1인당 금액"이 요약으로 표시되고, 참여자별로 "낸 돈 / 부담액 / 차액"을 보여줍니다.
- 차액을 바탕으로 실제 주고받아야 할 돈을 최소 횟수로 정리한 "OO → OO 00,000원" 목록이 함께 표시됩니다.

## 실시간 공유 (같이 편집)

모임 목록 화면 상단의 공유 아이콘을 누르면 "목록 공유하기" 버튼이 나옵니다. 누르면 그 시점의 모든 모임이 Firebase(Firestore)에 올라가고, 접속 주소 끝에 `?list=...`이 붙은 공유 링크가 생성됩니다. 이 링크를 받은 사람은 누구나 모임 목록 전체를 실시간으로 같이 보고, 그 안의 어떤 모임이든 지출을 기록하고, 새 모임을 추가할 수 있습니다. 공유 중에 새로 만드는 모임은 모두 자동으로 같은 목록에 등록되어 다른 사람에게도 바로 나타납니다.

- **개별 모임 단위 공유는 없습니다** — 공유는 항상 "모임 목록 전체" 단위입니다.
- **접근 방식**: 로그인/계정 없이 "링크를 아는 사람은 누구나 편집 가능"한 구조입니다 (구글 문서의 "링크가 있는 모든 사용자" 공유와 동일한 방식). 링크가 유출되면 그 사람도 목록 전체를 보고 고칠 수 있으니, 신뢰하는 사람에게만 링크를 공유하세요.
- 공유를 시작하면 인터넷 연결이 필요합니다. "공유 중지" 버튼으로 언제든 그 기기만 로컬 저장으로 되돌릴 수 있고(이 기기가 갖고 있던 모임들은 마지막으로 동기화된 상태로 로컬에 남습니다), 이후에도 다른 참여자들은 계속 실시간 공유를 이어갈 수 있습니다.
- Firestore 콘솔의 보안 규칙(테스트 모드는 30일 후 자동 만료됨)은 아래로 교체해서 계속 쓸 수 있게 해두세요:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /trips/{tripId} {
      allow read, write: if true;
      match /expenses/{expenseId} {
        allow read, write: if true;
      }
      match /packingItems/{itemId} {
        allow read, write: if true;
      }
    }
    match /lists/{listId} {
      allow read, write: if true;
      match /events/{eventId} {
        allow read, write: if true;
      }
    }
  }
}
```

## 준비물

하단 탭의 "준비물"에서 모임에 필요한 물건을 등록하고 담당자를 정할 수 있습니다.

- "참여자 관리"에서 준비물을 나눠 가져올 사람 이름(예: 규현, 인혁, 태균)과 그 사람이 대표하는 인원수(가족 단위 참여 시)를 등록하면 화면 상단에 표시됩니다. 인원수는 N빵 정산에서만 쓰이고, 준비물 배정에는 영향을 주지 않습니다.
- 준비물을 추가하면 표에 새 행으로 나타나고, 참여자(열)와 준비물(행)이 만나는 칸을 탭해서 담당자를 지정합니다. 이미 담당이 정해진 칸을 다시 탭하면 준비 완료로 체크됩니다. 준비물 이름을 탭하면 이름/메모 수정과 삭제가 가능합니다.
- 각 항목의 동그라미를 누르면 준비 완료로 체크되고, 상단에 "N / 전체 준비완료" 진행 상황이 표시됩니다.
- 공유 중인 모임이면 참여자, 준비물, 체크 상태 모두 실시간으로 같이 보고 편집됩니다.
